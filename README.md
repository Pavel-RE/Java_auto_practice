# Домашнее задание №1 - QA Java Auto

## Описание
Решение 12 задач на Java. Занятие 1

## Структура проекта
- `Task1.java` - проверка числа на четность
- `Task2.java` - проверка числа на положительность
- `Task3.java` - проверка доступа по возрасту
- `Task4.java` - оценка по баллам
- `Task5.java` - обратный отсчет
- `Task6.java` - поиск слова "bug" в массиве
- `Task7.java` - сумма чисел от 1 до n
- `Task8.java` - четные числа в диапазоне
- `Task9.java` - поиск максимального числа
- `Task10.java` - среднее арифметическое
- `Task11.java` - разворот массива
- `Task12.java` - удаление имени из списка

## Как запустить
Запустить `Main.java`
